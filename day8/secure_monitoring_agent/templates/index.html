Secure Monitoring Agent Manager Day 8

Operational logic and state-aware automation for the monitoring agent. Idempotent setup and live observability.

About this application

This application is a Secure Monitoring Agent Manager: a small background agent that periodically logs heartbeats, plus a manager script that ensures the agent is installed and running in a repeatable, safe way.

The manager script follows idempotency: you can run it multiple times and the result is the same (no duplicate users, no overwritten configs). It is state-aware: it checks whether the agent is already running before starting it, similar to a control loop that reconciles current state with desired state.

You run start.sh to bring up the agent and this dashboard; stop.sh stops both. The dashboard shows live system metrics and the latest agent log lines so you can see the application in operation.
