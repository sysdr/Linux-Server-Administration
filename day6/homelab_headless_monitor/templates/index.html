System Health Dashboard ●

About this project

Headless means no GUI: the system runs without a monitor or desktop. That saves resources and reduces attack surface. You interact remotely (SSH or this dashboard) instead of sitting at the machine.

This Health Monitor collects CPU, memory, disk, and uptime on the host it runs on. You can run it here with start.sh and observe live in this UI, or deploy the same script to a remote VM via SSH and run it on a schedule (e.g. cron) with output to a log file—same idea, different way to observe.

How it works

Setup: setup.sh creates the project; start.sh runs the health script and this dashboard. On a remote VM you could run the script via cron and tail a log file instead.
